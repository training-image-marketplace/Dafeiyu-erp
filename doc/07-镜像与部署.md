# 07 镜像与部署

> 这里讲「怎么把本系统做成一台学生能用的环境」。平台侧的容器编排见实训平台仓库的 `docs/07-容器实训`。

## 1. 单镜像

`erp-system/Dockerfile` 三段构建，最终产物是**一个** alpine 镜像：

```
node:22-alpine   → 构建前端（npm ci && npm run build → dist/）
golang:1.25      → 编译后端（CGO_ENABLED=0，静态二进制）
alpine:3.20      → 运行：./server + ./web，非 root 用户 app，EXPOSE 8889
```

两个刻意的设计：

- **用 `CMD` 而不是 `ENTRYPOINT`**：镜像广场需要在启动时覆盖命令（注入数据库连接信息），
  `ENTRYPOINT` 会把平台传入的 command 变成参数。
- **不内置 MySQL**：数据库是外部依赖，由平台按实例提供独立库（见 §3）。

```bash
cd erp-system
docker build -t practical-training/erp-system:2026.10 .
docker run --rm -p 8889:8889 practical-training/erp-system:2026.10
```

## 2. 镜像广场里的启动命令

平台创建容器时会把 `command` 原样作为容器的 `Cmd`。典型写法：

```json
["sh", "-c", "APP_ADDR=:8889 APP_DB_HOST=<mysql> APP_DB_PORT=3306 APP_DB_USER=<user> APP_DB_PASSWORD=<password> APP_DB_NAME=pt_erp APP_WEB_DIR=web APP_UPLOAD_DIR=/app/uploads INTERNAL_TOKEN=<token> ./server"]
```

- 容器端口填 `8889`；数据目录填 `/app/uploads`（或你自己的路径）。
- MySQL 在宿主机 Docker Desktop 上时用 `host.docker.internal`；远程节点换成容器可达的地址。
- `INTERNAL_TOKEN` 是平台下发开关的凭据。平台配了 `server.secret_key` 时会**改写**
  这处赋值为该实例派生的令牌；没配则要求这里与平台的 `erp.internal_token` 相同。

## 3. 每实例独立库

启用平台的 `instance_db` 后：

1. 平台按 `<prefix><env_uid>` 建一个**空库**（utf8mb4），并 `GRANT` 给 `app_user`；
2. 把启动命令里的 `APP_DB_NAME=<占位>` 改写为该库名；
3. 本系统启动时自己的迁移建表。

所以 `command` 里的 `APP_DB_NAME` 只是占位默认值，不会沿用 `pt_erp`。
删除实例时平台先销毁容器、再 `DROP DATABASE`；`destroy`（只销毁容器）不删库。

## 4. 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `APP_ADDR` | `:8889` | 监听地址 |
| `APP_ENV` | `prod` | `dev` 开 gin debug |
| `APP_DB_HOST` / `PORT` / `USER` / `PASSWORD` / `NAME` | — | 数据库连接 |
| `APP_WEB_DIR` | `web` | 前端产物目录（相对工作目录） |
| `APP_UPLOAD_DIR` | `uploads` | 上传落盘目录 |
| `APP_SECURE_COOKIE` | false | HTTPS 下必须 true |
| `APP_TRUSTED_PROXIES` | 空 | 逗号分隔；放在 nginx 后面必须填 |
| `INTERNAL_TOKEN` | 空 | 平台调用 `/internal/*` 的令牌；为空只允许 127.0.0.1 |
| `APP_DB_MAX_OPEN_CONNS` 等 | 见配置样例 | 连接池 |

完整列表与默认值见 `erp-system/server/config/config.example.yaml`。

## 5. 单独部署（不用平台）

一台 4C/8G 的机器足够一个班用共享实例：

1. 建库 `pt_erp`，建 `pt_app` 账号；
2. `docker run -d -p 8889:8889 -e APP_DB_HOST=... -e INTERNAL_TOKEN=... erp:<tag>`；
3. 前面放 nginx 时设 `APP_TRUSTED_PROXIES=127.0.0.1` 与 `APP_SECURE_COOKIE=true`；
4. 首次登录 `admin/admin123`，立即改密码。

> 单实例时所有学生共用一个 ERP，「个人/小组」级开关没有隔离意义——
> 那种场景要么每人一台容器，要么只按「全体」配开关。
